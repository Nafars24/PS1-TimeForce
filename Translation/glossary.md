# Translation Glossary

This glossary contains standardized terminology used throughout the Indonesian translation of **Power Rangers Time Force**.

The purpose of this glossary is to maintain consistent terminology across menus, gameplay instructions, tutorials, missions, dialogue, and system messages.

## Translation Style

The Indonesian localization follows these principles:

### 1. Natural Indonesian

Translations should sound natural to Indonesian players rather than following English sentence structure literally.

```text
Literal:
"Kamu akan perlu untuk..."

Preferred:
"Kamu harus..."
```

### 2. Short UI Text

Menu text should be concise.

```text
Select Character
→ Pilih Karakter

Controller Configuration
→ Konfigurasi Kontrol
```

### 3. Gameplay Instructions

Gameplay instructions should use direct and clear verbs.

```text
Defeat the enemies
→ Kalahkan musuh

Enter the door
→ Masuk ke pintu

Destroy the objects
→ Hancurkan benda
```

### 4. Consistent Terminology

The same English term should normally use the same Indonesian translation throughout the game unless context requires otherwise.

For example:

```text
Enemy → Musuh
Kick → Tndg
Jump → Lmpt
Punch → Pukul
```

### 5. Space Limitations

When the original game does not provide enough space for a natural Indonesian translation, abbreviations may be used.

The priority is:

```text
Natural Indonesian
        ↓
Short Indonesian
        ↓
Consistent abbreviation
        ↓
Preserve game stability
```

## Translation Status

This glossary is a living document.

New terminology should be added whenever a previously untranslated term is discovered during gameplay testing.

Before the final release, the glossary should be reviewed together with the complete translation database to ensure terminology consistency throughout the entire game.
